# ຕູ້ຄິດໄລ່ຫວຍ — Google Sheet Backend

ໄຟລ໌ `Code.gs` ສ້າງລະບົບຄົບຊຸດຕາມທີ່ຂໍໄວ້ ແລະ ໃຊ້ **API ດຽວກັນ** ກັບ
`index.html` ທີ່ສ້າງໄວ້ກ່ອນໜ້ານີ້ (checkUser, listUsers, addUser,
deleteUser, addEntries) — ດັ່ງນັ້ນເມື່ອ deploy ແລ້ວ ວາງ URL ໃສ່
`CONFIG.WEBAPP_URL` ໃນ index.html, ຕູ້ຄິດໄລ່ຈະສົ່ງຂໍ້ມູນເຂົ້າ Sheet
ນີ້ໄດ້ທັນທີ ໂດຍບໍ່ຕ້ອງແກ້ໄຟລ໌ HTML ຢ່າງອື່ນ.

## ວິທີຕິດຕັ້ງ

1. ສ້າງ Google Sheet ໃໝ່ (ຫຼືເປີດອັນເກົ່າ)
2. Extensions > Apps Script > ລຶບໂຄ້ດເດີມ > ວາງ `Code.gs` ທັງໝົດ
3. ບັນທຶກ (Ctrl+S) ແລ້ວກັບໄປໜ້າ Sheet, ໂຫລດໜ້າໃໝ່ — ຈະເຫັນເມນູ **"ຫວຍ"**
   ຢູ່ toolbar ດ້ານເທິງ
4. ກົດ ຫວຍ > **ຕັ້ງຄ່າຄັ້ງທຳອິດ (Setup)** — ຈະສ້າງທຸກຊີດ, ຕາຕະລາງ,
   ສູດ, ສີອັດຕະໂນມັດ ໃຫ້ອັດຕະໂນມັດ
5. Deploy > New deployment > ເລືອກ type = **Web app** >
   Execute as: **Me**, Who has access: **Anyone** > Deploy
6. ຄັດລອກ URL ທີ່ໄດ້ ໄປວາງໃສ່ `CONFIG.WEBAPP_URL` ໃນ `index.html`

ຄັ້ງຕໍ່ໄປ ຖ້າແກ້ໂຄ້ດແລ້ວຢາກ deploy ໃໝ່: ໃຊ້ **Manage deployments >
Edit > New version** (ບໍ່ແມ່ນ New deployment) ເພື່ອໃຫ້ URL ຄືເດີມ ບໍ່ຕ້ອງ
ແກ້ index.html ອີກ.

## ໂຄງສ້າງທີ່ໄດ້

| ຊີດ | ໜ້າທີ່ |
|---|---|
| **Dashboard** | ວັນທີອັດຕະໂນມັດ, ເລືອກຮອບ (ເຊົ້າ/ແລງ), ເລືອກຊີດງວດປັດຈຸບັນ, % ທີ່ໄດ້ (ແກ້ໄດ້), ຍອດລວມ/ຄ່າເປີເຊັນ/ຍອດສຸດທິ, ຊ່ອງໃສ່ເລກທີ່ອອກ → ຄິດຍອດຈ່າຍ → ກຳໄລ/ຂາດທຶນ ສີຂຽວ/ແດງອັດຕະໂນມັດ |
| **ຕາຕະລາງເລກ** | ເລກ 00–99, ຍອດຂາຍ, ຊື້ 2 ໂຕ, ຊື້ 3 ໂຕ, ລວມອັດຕະໂນມັດ — ອີງໃສ່ຊີດງວດທີ່ເລືອກໄວ້ໃນ Dashboard |
| **No1. / No2. / …** | ຊີດແຕ່ລະງວດ, ຄໍ B=ລຳດັບ C=ເລກ D=ລາຄາ (ຄືເດີມກັບ index.html), ສ້າງໃໝ່ບໍ່ຈຳກັດຜ່ານເມນູ "ສຳເນົາງວດໃໝ່" |
| **ສະຫລຸບ** | ຍອດຂາຍທັງໝົດ / ຍອດຈ່າຍ / ກຳໄລ (ດຶງຈາກ Dashboard) |
| **ລາຍງານລາຍວັນ** | ແຖວປະຫວັດ — ເພີ່ມທຸກຄັ້ງທີ່ກົດ "ບັນທຶກ" |
| **Users** (ເຊື່ອງໄວ້) | ບັນຊີຜູ້ໃຊ້ index.html (login gate ເດີມ) |

ເມນູ **ຫວຍ** ມີປຸ່ມ: ຄິດໄລ່ລວມທຸກຊີດ, ສຳເນົາງວດໃໝ່, ລ້າງຂໍ້ມູນຊີດ
ປັດຈຸບັນ, ບັນທຶກ, Export PDF, Export Excel, ສຳຮອງຂໍ້ມູນ — ໄຟລ໌ export/
backup ຖືກເກັບໄວ້ໃນໂຟນເດີ Drive ຊື່ "ຫວຍ - ສຳຮອງ/Export"

  ກົດ "ຄິດໄລ່ລວມທຸກຊີດ"
- ຕົວເລກ 3 ໂຕ ຈະຖືກນັບເຂົ້າຄໍ "ຊື້ 3 ໂຕ" ຂອງ 2 ໂຕທ້າຍ (ເຊັ່ນ 614 →
  ນັບເຂົ້າເລກ 14) ເພື່ອໃຫ້ກົງກັບຮູບແບບ ຫລັກ ໃນ index.html
- ການລວມຍອດຂອງ "ຕາຕະລາງເລກ" ຄິດຄືນໃໝ່ (ບໍ່ແມ່ນ live formula) ເພາະ
  Google Sheets ບໍ່ຮອງຮັບການລວມຫລາຍຊີດແບບ dynamic ດ້ວຍສູດຢ່າງດຽວ —
  ລະບົບຈະຄິດຄືນອັດຕະໂນມັດທຸກຄັ້ງທີ່ index.html ສົ່ງຂໍ້ມູນເຂົ້າມາ (ຜ່ານ
  ປຸ່ມ "ສົ່ງເຂົ້າຊີດ" / "ສົ່ງຍອດຄິດໄລ່ທັງໝົດ") ຫຼືກົດເມນູ "ຄິດໄລ່ລວມ" ເອງ

ຖ້າຢາກປ່ຽນອັດຕາຈ່າຍ, ຮູບແບບຄໍ, ຫຼືເພີ່ມ trigger ໃຫ້ຄິດໄລ່ອັດຕະໂນມັດ
ທຸກຄັ້ງທີ່ພິມໃສ່ Sheet ໂດຍກົງ (onEdit trigger) — ບອກໄດ້ ຈະເພີ່ມໃຫ້.
