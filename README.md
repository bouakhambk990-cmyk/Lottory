# BK Easy — ລະບົບຄິດໄລ່ຍອດ + ອອກບີນ + ຄົ້ນຫາຜົນຖືກ (Lottery Bet Calculator)

ແອັບເວັບໜ້າດຽວ (`index.html`) ສຳລັບຄິດໄລ່ຍອດເດີມພັນເລກ, ອອກບີນ, ບັນທຶກ/ຄົ້ນຫາຂໍ້ມູນຜ່ານ Google Sheet,
ແລະ ສະຫລຸບຍອດຮັບ-ສົ່ງປະຈຳວັນ — ໃຊ້ໄດ້ທັງແບບອອຟລາຍ (localStorage ຢູ່ອຸປະກອນດຽວ) ແລະ ແບບຊິ້ງຂໍ້ມູນຂ້າມ
ອຸປະກອນຜ່ານ Google Apps Script + Google Sheets.

## 📁 ໄຟລ໌ໃນໂປຣເຈັກນີ້

| ໄຟລ໌ | ໜ້າທີ່ |
|---|---|
| `index.html` | ແອັບເວັບທັງໝົດ (HTML+CSS+JS ຢູ່ໄຟລ໌ດຽວ) — ເປີດຜ່ານ browser ໄດ້ເລີຍ, ບໍ່ຕ້ອງຕິດຕັ້ງຫຍັງ |
| `Code.gs` | ໂຄ້ດ Google Apps Script (Backend) — ຮັບ-ສົ່ງຂໍ້ມູນລະຫວ່າງແອັບ ແລະ Google Sheet ຂອງທ່ານ |
| `README.md` | ໄຟລ໌ນີ້ |

> 💡 `Code.gs` ຖືກ generate ອອກມາຈາກໂຄ້ດທີ່ຝັງຢູ່ໃນ `index.html` ເອງ (ຕົວປ່ຽນແປງ `APPS_SCRIPT_CODE`).
> ໜ້າ "Admin" ຂອງແອັບກໍ່ມີປຸ່ມ "ຄັດລອກໂຄ້ດ Apps Script" ໃຫ້ຄັດລອກໂດຍກົງໄດ້ຄືກັນ ໂດຍບໍ່ຕ້ອງໃຊ້ໄຟລ໌ນີ້.

## 🚀 ວິທີຕິດຕັ້ງ (ຄັ້ງທຳອິດ)

### ຂັ້ນຕອນ 1 — ສ້າງ Google Sheet
1. ສ້າງ Google Sheet ໃໝ່ (ຫລືໃຊ້ຂອງເກົ່າ) — ນີ້ຄື "ຊີດຄວບຄຸມ" (Control Sheet) ໃຊ້ເກັບລາຍຊື່ຜູ້ໃຊ້ + ລະຫັດ Admin
2. ຄັດລອກ URL ຂອງຊີດນີ້ໄວ້ (ຈະໃຊ້ໃນຂັ້ນຕອນ 3)

### ຂັ້ນຕອນ 2 — Deploy Google Apps Script
1. ຈາກ Google Sheet ດ້ານເທິງ: ເມນູ **Extensions > Apps Script**
2. ລຶບໂຄ້ດຕົວຢ່າງທັງໝົດ ແລ້ວວາງເນື້ອໃນຈາກ `Code.gs` ລົງແທນ (ຫລືຄັດລອກຈາກໜ້າ Admin ຂອງແອັບ)
3. ກົດ **Deploy > New deployment**
   - ເລືອກ type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
4. ກົດ Deploy → ອະນຸຍາດສິດ (Authorize) ຕາມທີ່ Google ຖາມ
5. ຄັດລອກ **Web app URL** ທີ່ໄດ້ (ລົງທ້າຍດ້ວຍ `/exec`)

### ຂັ້ນຕອນ 3 — ຕັ້ງຄ່າໃນ `index.html`
ເປີດ `index.html` ດ້ວຍ text editor, ຫາຕົວປ່ຽນແປງ `CONFIG` (ໃກ້ໆຫົວ script) ແລ້ວແກ້:

```js
var CONFIG = {
  WEBAPP_URL: '<Web app URL ຈາກຂັ້ນຕອນ 2>',   // ຕ້ອງລົງທ້າຍດ້ວຍ /exec
  SHARED_TOKEN: 'bk123',                       // ຕ້ອງກົງກັບ SHARED_TOKEN ໃນ Code.gs
  ADMIN_PASSWORD: '<ຕັ້ງລະຫັດ Admin ຂອງທ່ານເອງ>',
  CONTROL_SHEET_URL: '<URL Google Sheet ຈາກຂັ້ນຕອນ 1>',
  SHEET_TAB: 'No1.',
  ...
};
```

> ⚠️ `SHARED_TOKEN` ໃນ `index.html` ແລະ `Code.gs` **ຕ້ອງກົງກັນທຸກໂຕອັກສອນ** ບໍ່ດັ່ງນັ້ນທຸກຄຳຂໍຈະຖືກປະຕິເສດ.

### ຂັ້ນຕອນ 4 — ເປີດໃຊ້
ເປີດ `index.html` ຜ່ານ browser (ອັບໂຫລດຂຶ້ນເວັບໂຮສຕິ້ງ ຫລືເປີດຜ່ານໄຟລ໌ໂດຍກົງກໍ່ໄດ້) → ເຂົ້າ Admin ຄັ້ງທຳອິດເພື່ອສ້າງບັນຊີຜູ້ໃຊ້ ແລະ ຕັ້ງ Google Sheet ສ່ວນຕົວຂອງແຕ່ລະຜູ້ໃຊ້.

## 🗂️ ໂຄງສ້າງ Google Sheet ຂອງແຕ່ລະຜູ້ໃຊ້

ແຕ່ລະຜູ້ໃຊ້ຕັ້ງ Google Sheet ຂອງຕົນເອງໄວ້ (ຢູ່ Admin) — ແອັບຈະສ້າງແທັບເຫລົ່ານີ້ໃຫ້ອັດຕະໂນມັດ:

| ແທັບ | ໃຊ້ເກັບຫຍັງ |
|---|---|
| **Bills** | ບີນທີ່ອອກ (ສະກຸນ **ກີບ**) — ວັນທີ, ເວລາ, ເລກທີ່ບີນ, ຜູ້ໃຊ້, ຊຸດເລກບົນ, ຊຸດເລກລ່າງ, ລວມລາຄາ |
| **Bills_THB** | ບີນທີ່ອອກ (ສະກຸນ **ບາດ**) — ໂຄງສ້າງດຽວກັນກັບ Bills, ແຍກຊິດອັດຕະໂນມັດເມື່ອພິມລາຄາຕໍ່ທ້າຍດ້ວຍ `฿`/`ບາດ`/`บาท`/`บาด`/`B`/`b` |
| **Results** | ຜົນເລກ + ອັດຕາຈ່າຍ ທີ່ບັນທຶກໄວ້ຕໍ່ວັນທີ (ໃຊ້ຮ່ວມກັນຂ້າມອຸປະກອນ) |
| **Summary** | ສະຫລຸບຍອດຮັບ-ສົ່ງປະຈຳວັນ (ສະກຸນກີບ) — upsert ຕໍ່ວັນທີ |
| **Summary_THB** | ສະຫລຸບຍອດຮັບ-ສົ່ງປະຈຳວັນ (ສະກຸນບາດ) |
| **Board** | ຂໍ້ມູນຕາຕະລາງເລກ (Number Board) ຂອງຜູ້ໃຊ້ນັ້ນ |

ຊີດຄວບຄຸມ (Control Sheet — URL ດຽວກັນສຳລັບທຸກຜູ້ໃຊ້) ຈະມີແທັບເພີ່ມ:

| ແທັບ | ໃຊ້ເກັບຫຍັງ |
|---|---|
| **Users** | ລາຍຊື່ຜູ້ໃຊ້ທັງໝົດ + ວັນໝົດອາຍຸ + Sheet URL ຂອງແຕ່ລະຄົນ |
| **Config** | ລະຫັດ Admin, ຂໍ້ຄວາມລາຍເຊັນທ້າຍບີນ (brand text), ຄ່າຕັ້ງອື່ນໆລວມ |

## ✨ ຄວາມສາມາດຫລັກ

- **ຄິດໄລ່ຍອດເດີມພັນ** — ພິມລາຍການເລກ+ລາຄາຮູບແບບອິດສະຫລະ (`19=10`, `12-52-92=10ບາດ`, `ບົນລ່າງ`, `ໂຕລະ`, ລ້ານ/ແສນ ແລະ ອື່ນໆ)
- **ອອກບີນ** — ພິມບີນອອກ, ບັນທຶກລົງ Google Sheet ອັດຕະໂນມັດ (ແຍກຊິດຕາມສະກຸນເງິນ)
- **ຄົ້ນຫາບີນຖືກ** — ໃສ່ຜົນເລກ (2 ໂຕ/3 ໂຕ/2 ໂຕລ່າງ) + ວັນທີ + ຊ່ວງເວລາຮັບ + ສະກຸນເງິນ → ຄົ້ນຫາທຸກບີນທີ່ຖືກ ພ້ອມຄາດຄະເນຍອດຈ່າຍ (ປັດເສດເປັນຫລັກພັນ)
- **ບັນທຶກຜົນເລກ** ລົງ Google Sheet ໃຫ້ໃຊ້ຮ່ວມກັນຂ້າມອຸປະກອນໄດ້
- **ສະຫລຸບຍອດຮັບ-ສົ່ງປະຈຳວັນ** — ອ່ານທຸກບີນຂອງວັນທີນັ້ນຈາກ Sheet ຈິງ, ຄິດຄອມ, ຫັກລາງວັນ, ບອກ "ສົ່ງແມ່"(+)/"ສົ່ງລູກ"(−) ພ້ອມໄຮໄລສີ
- **ຮອງຮັບ 2 ສະກຸນເງິນ** (ກີບ/ບາດ) ແຍກຄິດ-ແຍກຊິດ-ແຍກສະຫລຸບອັດຕະໂນມັດ
- **ຕາຕະລາງເລກ (Number Board)** ຊິ້ງຂໍ້ມູນຂ້າມອຸປະກອນພາຍໃນຜູ້ໃຊ້ດຽວກັນ
- **ອ່ານບີນຈາກຮູບ (OCR)** ສຳລັບຄັດລອກຂໍ້ມູນບີນເກົ່າ
