ເຂົ້າສູ່ລະບົບ

ພິມຊື່ຜູ້ໃຊ້ທີ່ admin ໄດ້ຕັ້ງໃຫ້ທ່ານ. ຖ້າຊື່ໝົດເວລາ ຫຼືບໍ່ພົບ ຈະເຂົ້າໃຊ້ບໍ່ໄດ້.

📖 ຄຳແນະນຳ ການພິມ (Syntax)

ໜຶ່ງແຖວ = ໜຶ່ງລາຍການ. ຄັ່ນເລກດ້ວຍ , . - ; / ຫຼືວັກ. ຄັ່ນລາຄາດ້ວຍ : = ຮູ ຮູ້ ຮູລະ. ລາຄາເປົ່າໆ = ພັນ (: 5 → 5,000) · ລ້ານ = ລ້ານ · ແສນ = ແສນ · ຕໍ່ທ້າຍດ້ວຍ ฿ ຫຼື ບາດ = ນັບເປັນມູນຄ່າຈິງ ບໍ່ຄູນພັນ.

20*10 ແຍກ 2 ລາຄາໃນຊຸດດຽວ. ໃສ່ ບລ ຫຼື ບົນ-ລ່າງ ໃນແຖວ (ຫຼືແຖວແຍກຕໍ່ທ້າຍ) ເພື່ອຄູນ 2 ສະເພາະຊຸດເລກ 2 ໂຕ.

ພິມເລກລ້ວນໆ ຫຼາຍແຖວຕິດກັນ ແລ້ວປິດທ້າຍດ້ວຍແຖວລາຄາຢ່າງດຽວ (=200฿) ເພື່ອໃຫ້ລາຄານັ້ນນຳໃຊ້ກັບທຸກແຖວເລກຂ້າງເທິງ.

ຫລັກ (ຫຼັກ): ໃສ່ຫລັງແຖວຊຸດເລກ 2 ໂຕ ເພື່ອເອົາເລກທີ່ລະບຸໄປ "ຕໍ່ໜ້າ" ຊຸດເລກນັ້ນ ໃຫ້ກາຍເປັນເລກ 3 ໂຕ ໃນລາຄາໃໝ່ຂອງມັນເອງ ເຊັ່ນ ຫລັກ 8 7 3 = 10 ຈາກຊຸດ 14 24 ຈະໄດ້ 814 824 714 724 314 324 ລາຄາ 10. ໃສ່ໄດ້ຫລາຍແຖວຕິດກັນ ແຕ່ລະແຖວມີລາຄາຂອງໂຕເອງ ໂດຍທຸກແຖວຫລັກຈະໃຊ້ຊຸດເລກ 2 ໂຕ "ຕົ້ນສະບັບ" ອັນດຽວກັນ (ບໍ່ແມ່ນຕໍ່ຈາກຫລັກແຖວກ່ອນ). ຖ້າແຖວຊຸດເລກ 2 ໂຕ ບໍ່ມີລາຄາຂອງມັນເອງ (ບໍ່ພິມ =) ມັນຈະບໍ່ຖືກຄິດເງິນ ຖືກໃຊ້ເປັນພຽງຊຸດຕົ້ນສະບັບໃຫ້ຫລັກແຖວຂ້າງລຸ່ມເທົ່ານັ້ນ.

ຈະສົ່ງໄປ Google Sheet ຂອງ: —

ຈັດການຜູ້ໃຊ້ (Admin)

ໃສ່ ອີເມວ Gmail ຂອງຜູ້ໃຊ້ນີ້ ແລ້ວປ່ອຍຊ່ອງ Sheet URL ໄວ້ວ່າງ — ລະບົບຈະ ສ້າງ Google Sheet ໃໝ່ໃຫ້ອັດຕະໂນມັດ (ເປັນເຈົ້າຂອງໂດຍບັນຊີ Google ຂອງ Admin ທີ່ deploy Apps Script) ແລະ ແບ່ງປັນສິດແກ້ໄຂ (Editor) ໃຫ້ອີເມວນັ້ນທັນທີ — ໝາຍຄວາມວ່າ Admin ເປັນຄົນຄວບຄຸມ/ກຳນົດສິດທັງໝົດ ຜູ້ໃຊ້ຈະເຫັນສະເພາະຊີດຂອງໂຕເອງເທົ່ານັ້ນ. ຖ້າຢາກໃຊ້ຊີດທີ່ມີຢູ່ແລ້ວ (ບໍ່ໃຫ້ລະບົບສ້າງໃໝ່) ໃຫ້ວາງລິ້ງໃສ່ຊ່ອງ Sheet URL ໄດ້ເລີຍ — ລະບົບຈະໃຊ້ຊີດນັ້ນແທນ ແລະ ບໍ່ສ້າງໃໝ່ (ແຕ່ Admin ຕ້ອງແຊຣ໌ສິດແກ້ໄຂໃຫ້ຜູ້ໃຊ້ນັ້ນເອງ ຖ້າຢາກໃຫ້ຜູ້ໃຊ້ເປີດເບິ່ງຊີດໄດ້ໂດຍກົງ).

💻 ໂຄ້ດ Google Apps Script (Router) — ກັອບປີ້ໄປວາງໃສ່ Apps Script ຫຼັກ

ວາງໂຄ້ດນີ້ໃສ່ Google Apps Script ຂອງ "ຊີດຫຼັກ" (ຊີດທີ່ເກັບລາຍຊື່ຜູ້ໃຊ້ ຄໍ A=username, B=expiry ISO, C=Google Sheet URL, D=email, ໃນແຖບຊື່ Users) ແລ້ວ Deploy ເປັນ Web App (Execute as: Me, Who has access: Anyone) — ຈາກນັ້ນເອົາ URL ທີ່ໄດ້ມາໃສ່ໃນ CONFIG.WEBAPP_URL ຢູ່ຫົວໄຟລ໌ index.html. ໂຄ້ດນີ້ຈະ ສ້າງ + ແບ່ງປັນ Google Sheet ອັດຕະໂນມັດ ໃຫ້ອີເມວທີ່ Admin ໃສ່ໄວ້.
